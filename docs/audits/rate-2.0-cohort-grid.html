How to read it

The large figure is EXPECTED; beneath it the LOW–HIGH range and the confidence mark. Tint depth tracks magnitude on a log scale, so the shape of a card is visible across five orders of magnitude.

1 of 2 means only one run produced a figure. Run spread shows how far the two runs diverged — blank where they agreed closely.
