3 · Historical window & limits

Discovery mediamedia.limit(10) — the last 10 posts, no pagination implemented
Connected medialimit=25 per call; the sync paginates for backfill (instagramSync.ts)
Account insightsperiod=day — a point-in-time value, no history returned. Our time series is reconstructed by snapshotting daily.
Demographicsperiod=lifetime, one API call per breakdown (4 calls)
Token60-day long-lived, refreshed via ig_refresh_token
Business DiscoveryBusiness/Creator accounts only — a personal account returns not_business_account

4 · What we derive

DerivedFormula as implemented
avg_engagement_rateReach-based when per-post reach exists: Σ total_interactions ÷ Σ reach. Falls back to (avg_likes + avg_comments) ÷ followers. DERIVED
The comment gives the reason: a viral Reel put reach at ~8× followers and a follower-based rate read 54.6% where the reach-based rate read ~7%.
content_frequencyposts ÷ weeks across the observed window, from sorted timestamps, ≥2 posts required
posts_last_30dExact count within 30 days — used by scoring, unlike the display metrics
avg_reach_per_post · avg_saves_per_post · avg_shares_per_postMean over posts that returned that insight
avg_views_per_postnull — needs a per-type video metric; marked future in code
discovery.{reels,total_reach,avg_reach}Trial/Discovery Reels segmented out: is_shared_to_feed=false AND reach ≥ 2× followers, so non-follower spikes don't inflate core reach
top_audience_*First row of each sorted demographic breakdown

Historical window

The Analytics API is the only source with real history — it accepts a start and end date and returns a 30-day window. Everything else across all three platforms is point-in-time, and our history exists only because we snapshot daily.

TikTok

No public path

There is no discovery equivalent. discovery.ts states it: "TikTok has no free route (provider, later)." So every TikTok field below requires the athlete to connect, and TikTok peer benchmarking is impossible at any currently-approved cost.

Notable

TikTok returns no reach or impressions at all — view_count is the closest analogue. And unlike Instagram, per-video engagement needs no separate insights call: view/like/comment/share come back with the list.

TIKTOK — everything

No public path exists, so every field listed in the TikTok section is OAuth-only. Audience demographics are unlocked in principle by the creator_info scope but are disabled in code today.

The through-line

Across all three platforms the split is the same: likes, comments, follower counts and timestamps are public; reach, saves, shares, watch time and audience demographics are owner-only. No amount of API work changes that — it is a platform privacy boundary, not a gap in our implementation.
